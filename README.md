# صفوة للبخور

متجر إلكتروني مبني بـ Next.js، جاهز للنشر على Vercel.

- **بيع سريع**: زر «شراء سريع» على كل منتج يفتح نافذة لاختيار الكمية والدفع مباشرة دون المرور بالسلة، أو الطلب عبر واتساب.
- **سلة مشتريات** تُحفظ في المتصفح، وشحن مجاني فوق مبلغ محدد.
- **التحويل البنكي (آيبان)** — طريقة الدفع الافتراضية: بعد تأكيد الطلب يرى العميل المبلغ ورقم الآيبان مع زر نسخ، ثم يرسل الطلب وإيصال التحويل عبر واتساب.
- **الدفع عند الاستلام**: يُرسل الطلب كاملاً إلى واتساب المتجر.
- **الدفع الإلكتروني عبر [ميسر](https://moyasar.com)** (اختياري): مدى، فيزا، ماستركارد. لا يظهر إلا بعد إضافة مفاتيح ميسر.
- **واتساب**: زر عائم ورابط في كل صفحة على الرقم +966 50 152 3258.
- **شعار** المبخرة في `public/logo.svg` و `app/icon.svg`.
- **لوحة تحكم** على `/manager`: تسجيل دخول، استقبال الطلبات وتحديث حالتها، فواتير قابلة للطباعة، وإضافة المنتجات وتعديلها وإخفاؤها ورفع صورها.

## لوحة التحكم (/manager)

تحتاج ثلاثة أشياء في Vercel (المشروع ← Settings / Storage):

1. **بيانات الدخول**: في Environment Variables أضف `ADMIN_EMAIL` و `ADMIN_PASSWORD` (كلمة سر قوية، 12 حرفاً على الأقل)، ثم Redeploy.
2. **قاعدة البيانات**: Storage ← Create / Connect ← **Upstash for Redis** ← اربطه بالمشروع. يضيف المتغيرات تلقائياً.
3. **صور المنتجات** (اختياري): Storage ← **Blob** ← أنشئ متجراً **Public** واربطه بالمشروع.

بدون قاعدة البيانات يعمل المتجر بالمنتجات الموجودة في `lib/products.ts`، لكن الطلبات لا تُحفظ ولا يمكن تعديل المنتجات من اللوحة.
بعد أول حفظ من اللوحة تصبح المنتجات في قاعدة البيانات، ولا يؤثر تعديل `lib/products.ts` على المتجر.

## التعديل

| ماذا | أين |
| --- | --- |
| بيانات الآيبان، رسوم الشحن، حد الشحن المجاني | لوحة التحكم `/manager/settings` |
| اسم المتجر، الواتساب، المدن | `lib/config.ts` |
| المنتجات والأسعار والأوصاف | لوحة التحكم `/manager/products` |
| الألوان والتصميم | `app/globals.css` |

## التشغيل محلياً

```bash
npm install
cp .env.example .env.local   # ضع مفاتيح ميسر التجريبية
npm run dev
```

## النشر على Vercel

1. في Vercel: **Add New → Project** واختر هذا المستودع. الإعدادات تُكتشف تلقائياً (Next.js).
2. في **Settings → Environment Variables** أضف:
   - `NEXT_PUBLIC_MOYASAR_PUBLISHABLE_KEY` — المفتاح العام من ميسر
   - `MOYASAR_SECRET_KEY` — المفتاح السري من ميسر
   - `NEXT_PUBLIC_MOYASAR_METHODS` — مثلاً `creditcard` أو `creditcard,applepay,stcpay`
   - `NEXT_PUBLIC_SITE_URL` — رابط موقعك النهائي، مثل `https://ba5or.vercel.app`
3. أعد النشر (Redeploy) بعد إضافة المتغيرات، لأن متغيرات `NEXT_PUBLIC_` تُضمَّن وقت البناء.

مفاتيح ميسر اختيارية: بدونها يعمل المتجر بالتحويل البنكي والدفع عند الاستلام فقط.

## ملاحظات مهمة عن الدفع

- **التحقق من الدفع يتم في الخادم**: بعد الدفع تجلب صفحة `/checkout/result` العملية من ميسر بالمفتاح السري، وتعيد حساب قيمة الطلب من الكتالوج وتطابقها مع المبلغ المدفوع.
- **حفظ الطلبات**: كل طلب يُحفظ في قاعدة البيانات لحظة تأكيده ويظهر في لوحة التحكم، والدفع الإلكتروني المؤكد يغيّر حالته إلى «مدفوع» تلقائياً. بدون قاعدة بيانات تصل الطلبات عبر واتساب فقط.
- **Apple Pay** يتطلب توثيق النطاق: نزّل ملف `apple-developer-merchantid-domain-association` من لوحة ميسر وضعه في `public/.well-known/`، ثم أضف `applepay` إلى `NEXT_PUBLIC_MOYASAR_METHODS`.
- **STC Pay** يجب تفعيله من حسابك في ميسر أولاً.
- اختبر بمفاتيح `pk_test_` / `sk_test_` وبطاقات الاختبار من [توثيق ميسر](https://docs.moyasar.com) قبل التحويل لمفاتيح الإنتاج.
